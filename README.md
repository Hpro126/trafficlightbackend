# 🚦 Smart Traffic AI Backend

Backend server for a smart traffic light system using **2 ESP32 AI Thinker cameras**.

The backend receives live camera frames, processes traffic data, and provides outputs for a website dashboard and traffic light controller.

---

## 🚀 Features

- Receive live JPEG frames from 2 ESP32-CAM cameras
- Separate camera feeds:
  - North → South traffic camera
  - East → West traffic camera
- Provide live camera images to frontend
- Ready for AI vehicle detection integration
- Ready for traffic signal automation
- Deployable on Render
